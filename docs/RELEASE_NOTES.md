## TG Sales CRM

**Download `tg_sales_windows_x64_v<version>.zip`** below (the "Source code"
archives are for developers and do not contain the app).

1. Check the download: its SHA-256 must match `SHA256SUMS.txt`.
2. Extract the whole ZIP to a folder you can write to.
3. Double-click `launch.bat`. Your browser opens TG Sales CRM. Keep the
   tg_sales window open while you work; close it or run `stop.bat` to quit.

Nothing else needs to be installed. Your data stays in
`%LOCALAPPDATA%\TatumGames\tg_sales`; to update, replace the program folder
with the new release. The program is not code-signed yet, so Windows may show
a SmartScreen warning ("More info" › "Run anyway" after checking the hash).

See CHANGELOG.md for what changed, and docs/USER_GUIDE.md for how to use it.
